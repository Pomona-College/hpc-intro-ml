Discover how to apply machine learning to complex research problems using the computational power of Sagehen HPC. This workshop introduces practical machine learning on HPC systems, covering environment setup, data preparation, training models with PyTorch and TensorFlow, and managing long-running training jobs. You'll learn to scale your machine learning workflows to leverage multiple CPU cores and GPU acceleration. This workshop is part of the Pomona College HPC Workshop Series.

::::::::::::::::::::::::::::::::::::: prereq

## Prerequisites

This workshop is part of the **Pomona College Research Computing Workshop Series**
for researchers using the **Sagehen HPC cluster**.

Before starting, ensure you have:
- Completed Workshop 16 (GPU Computing) or equivalent GPU experience
- Python proficiency required
- A Sagehen HPC account (request from [its-hpc@pomona.edu](mailto:its-hpc@pomona.edu))
- Access to the [OnDemand portal](https://ondemand.hpc.pomona.edu)

For questions or support, contact the Research Computing team at
[its-hpc@pomona.edu](mailto:its-hpc@pomona.edu).

:::::::::::::::::::::::::::::::::::::

Designed for researchers new to machine learning on HPC systems, this workshop assumes basic Python knowledge and familiarity with HPC concepts. You will gain practical skills in building, training, and optimizing machine learning models on Sagehen's computational resources.
